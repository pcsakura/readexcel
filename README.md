## 💡 为什么需要这个工具？

在日常财务核算、仓库盘点、信息录入、人事档案比对等工作中，人工核对 Excel 往往面临几大痛点：
1. **眼睛易疲劳，容易串行/看错位**：对着密集表格看几百行，极易产生视觉疲劳。
2. **传统语音软件“机械味”浓重**：旧式合成器声音生硬冰冷、缺乏抑扬顿挫，听几分钟便头昏脑胀。
3. **表格放大后“看不全”**：为了看清小字把表格放大到 200%~300%，一屏只能看几行，朗读到屏幕外时单元格根本看不到。
4. **两两配对数据换行繁琐**：核对“姓名+身份证”或“单号+金额”时，右侧常常有一堆公式辅助列，传统读法整行通读效率极低。

**Excel 智能核对朗读助手**正是为了从根本上解决上述痛点而诞生的专用生产力工具！

## 🌟 核心功能详解

### 1. 🎙 微软研究院高拟人度神经网络语音 (Neural TTS)
- 集成微软 Azure / Edge 最新深度学习语音模型，彻底告别传统合成器的生硬机械音。
- **真实语调与呼吸感**：发音温和自然、抑扬顿挫，报读金额千分位（如 `¥12,850.50`）与长串数字（如身份证、单号）格外清晰精准。
- **多款精选音色随意切换**（并配有 **【🔊 试听音色】** 按钮）：
  - **【微软晓晓】温和甜美女声（推荐 · 默认）**：最逼真拟人，播音级听感。
  - **【微软云希】阳光青年男声（表格核对首选）**：吐字利落、干脆清晰。
  - **【微软云健】成熟稳重男声**：适合核对严肃账单、审计与财务数据。
  - **【微软晓艺】亲切自然女声**：轻松日常感。
  - **【东北晓北】生动幽默女声**：特色口音，长时间核验防困提神。
  - **【本地离线】微软慧慧**：无网络环境自动平滑兜底。

### 2. 🔴 动态红色粗边框聚焦 (0 污染原表样式)
- 朗读到当前单元格时，程序会在其正上方瞬间悬浮一个 **2.5pt 纯红色的无填充矢量瞄准框**。
- **绝不修改原表格的边框线、背景填充或字体格式**，朗读停止时自动无痕销毁，表格始终保持 100% 原始样貌。

### 3. 🔍 超视距平滑居中滚屏 (突破屏幕缩放限制)
- 当把 Excel 放大至 **200% ~ 400%** 以看清小字时，屏幕可见行列极少。
- 程序实时计算 Excel 窗口的当前视口边界；当朗读到屏幕边缘或外部单元格时，**自动命令 Excel 视口滚动并把当前单元格调整到视野正中央偏上**，无需手动拨动鼠标滚轮。

### 4. 🧭 灵活的核对轨迹规划
- **完整逐列朗读（默认推荐）**：整列从上到下读完，自动切换至下一列，垂直长表格核验首选。
- **横向读 N 格换行（默认 N=2）**：两两配对核对神器！每行只读前 2 个单元格，读完立即跳转到下一行，完美契合“姓名+电话”、“单号+金额”核对，自动跳过右侧无关列。
- **完整逐行朗读**：从左到右整行读完换下一行。

### 5. ⚡ 专属空格键控制 (绝不干扰其他应用打字)
- 彻底摒弃粗暴的全局钩子，改为窗口级安全响应。
- 只要鼠标点击一下本助手悬浮窗（使其获得焦点）：
  - **未开始状态**：按一次【空格键】 -> **直接启动朗读**
  - **朗读进行中**：按一次【空格键】 -> **毫秒级即时暂停**
  - **已暂停状态**：按一次【空格键】 -> **立即恢复继续**
- 切换到微信、Word、浏览器或在 Excel 单元格内编辑公式打字时，空格键完全正常，**绝不产生任何按键抢占或干扰**。

### 6. ⏱ 单元格停顿与语速调节
- **格间停顿**：严格静音延时（0.0 秒 ~ 3.0 秒），让人耳有充分反应时间，并配备快捷预设按钮：
  - **0.2s 紧凑** | **0.5s 适中 (默认)** | **0.8s 从容** | **1.2s 仔细**
- **语速倍率**：大号滑块支持 **0.7x (慢速) ~ 1.8x (极速)** 明显调节，方便提速核验。

### 7. 💾 全选项自动持久化记忆
- 默认已为您预设最佳习惯：**“整张工作表” + “竖向整列读完换下一列”**。
- 您在界面上做出的任何改动（音色、倍速、停顿、红框、跳空等），都会**实时自动保存到本地 `config.json`**，第二次启动 100% 自动还原！

## 📖 怎么使用：手把手实操指南

### 1. 运行前准备
* **系统环境**：Windows 10 / Windows 11 (64位)
* **Office 软件**：已安装 Microsoft Office Excel（2016 / 2019 / 2021 / Office 365 均可）
* **依赖安装**：在项目根目录下打开命令行运行：
  ```bash
  pip install -r requirements.txt
  ```

### 2. 启动助手
* **最简启动**：直接双击文件夹中的 [`启动朗读助手.bat`](启动朗读助手.bat)（会自动在后台调起悬浮窗，不留黑色终端窗口）。
* **命令行启动**：输入 `python excel_reader.py`。

### 3. 三种典型核对场景使用示例

#### 场景 A：整张长表格单列 / 多列连续核对（最常用）
1. 打开 Excel 表格；
2. 保持助手默认设置（**整张工作表** + **完整逐列朗读**）；
3. 点击 **【▶ 开始朗读】**（或点击悬浮窗按空格键）；
4. 程序将自动从第 1 列第 1 行自上而下逐个朗读，每读一个单元格，Excel 屏幕上均有红框跟随，整列读完自动进入下一列。

#### 场景 B：“姓名 + 身份证号 / 电话”两两配对核对
1. 打开人员名单表格；
2. 在助手界面轨迹规划中选择 **【横向读 [ 2 ] 个单元格，然后换下一行】**；
3. 点击 **【▶ 开始朗读】**；
4. 助手将先读第 1 行的姓名与身份证，随后**立即跳到第 2 行**读取对应的姓名与身份证，完全不理会后面的籍贯、邮箱等无关列！

#### 场景 C：局部选区精细排查
1. 用鼠标在 Excel 表格中框选出您想核对的具体区域（例如 `C5:E20`）；
2. 在助手范围选项中选择 **【当前选中区域】**；
3. 点击 **【▶ 开始朗读】**，程序仅在您框选的区域内循环朗读。

## ⌨️ 专属快捷键速查

为了保证纯粹舒适的盲听与核对体验，所有快捷键均支持单击助手窗口后直接触发：

| 快捷键 | 对应动作 | 使用说明 |
| :--- | :--- | :--- |
| **【空格键 (Space)】** | **启动 / 暂停 / 恢复** | 未开始时按空格直接启动；朗读中按空格暂停；暂停后按空格继续。 |
| **【Esc 键】** | **停止朗读** | 立即停止朗读、清空语音队列并清除 Excel 上的红色方框。 |
| **【← 左箭头】** | **重读当前 / 上一格** | 没听清数字或想反复确认时，按一下即可倒带重读。 |
| **【→ 右箭头】** | **跳至下一格** | 当前单元格已知无误，跳过直接读下一项。 |

## 🛠 底层技术与架构

1. **拒绝模拟键盘按键**：
   - 坚决不用不可靠的 `SendKeys` 上下左右模拟按键；
   - 通过 Windows 官方 COM 原生对象接口（`win32com.client`）与 Excel 内核直接通信，直接读取屏幕格式化后的直观文字（`cell.Text`），精准定位坐标，**只读访问，绝不改动任何数据**。
2. **异步音频预生成流水线 (Prefetch Pipeline)**：
   - 在播放当前单元格发音时，后台守护线程已经提前将下一个单元格的神经网络音频请求并合成完毕；
   - 彻底抹平网络延迟，实现无缝连贯、如本地般的丝滑播放。
3. **动态透明矢量 Shape 覆盖**：
   - 使用 Excel 内置 Shape 矢量层贴合单元格移动，无须改动单元格边框或颜色，实现零侵入、零污染。

## 🛡 数据安全与隐私承诺

- **纯本地运算与只读调用**：本程序除调用微软官方神经语音合成接口将单格文本转换为临时发音音频外，**绝不会把您的任何 Excel 工作簿文件、表格结构或隐私信息上传到任何服务器**。
- **即用即焚**：生成的单元格发音临时音频在播放结束后立即由系统自动销毁，零文件残留。
